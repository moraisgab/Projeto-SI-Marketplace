Este repositório armazena a documentação técnica da plataforma de marketplace da startup Digibuybr, desenvolvida para a disciplina de Business Systems Planning, Analysis & Design. O diretório LevantamentoRequisitos, localizado na branch develop, é destinado exclusivamente ao armazenamento dos artefatos de engenharia de requisitos do projeto. Neste local, deve ser depositado o documento em PDF contendo a lista detalhada de requisitos funcionais e não funcionais, o quadro de análise de valor baseado no modelo de Design Thinking e as referências de mercado utilizadas para o benchmarking das funções.
